# Integration handoff

Integrate only after Stage 1 is independently proven.

Hostile review before integration must test:
- no escalation from cycle number alone;
- same-signature evidence cannot be spoofed by infrastructure errors;
- patch-contract and controller faults remain terminal, not escalation signals;
- changed failure family resets to Low Heat;
- retained partial-win next target resets to Low Heat;
- insufficient fuel blocks Terra/Sol before the call;
- repeated Sol failure stops;
- fixed modes do not auto-escalate;
- Windows-native acceptance.
