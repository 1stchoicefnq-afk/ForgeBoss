# Support

ForgeBoss is under active development and is not yet a production support product.

For normal bugs, setup problems and feature requests, use GitHub Issues and include enough detail for someone else to reproduce the problem.

Before opening an Issue:

1. check the README and existing Issues;
2. confirm you are testing current `main` where practical;
3. remove API keys, tokens, private repository data and customer information from logs.

For security-sensitive reports, follow `SECURITY.md` instead of posting exploitable details publicly.

Community help is best-effort. A response time or fix is not guaranteed.
