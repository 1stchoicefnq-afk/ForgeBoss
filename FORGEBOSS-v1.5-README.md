# ForgeBoss v1.5 — Single-Failure Repair

The repeated Luna safe-refusal came from a contract conflict: the compact focused packet contained one narrow
failure, while Repair Rat's inherited prompt still asked for multiple PostgreSQL failure families to be understood
together.

Focused mode now repairs ONE primary failure family per paid cycle. A separate secondary failure can no longer block
a well-supported narrow repair. ForgeBoss still runs the whole suite afterward; whatever remains becomes the next
cycle's evidence.

Focused mode also refuses to silently widen its write allowlist back to the full controller scope, and duplicate
safe-refusal activity messages are collapsed in the desktop timeline.
