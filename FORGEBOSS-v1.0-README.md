# ForgeBoss v1.0 — Insight Dashboard + Productive Safe Refusals

Safe refusals are now useful evidence, not repeated cheap calls.

If an AI produces no patch and explains that evidence is insufficient:
1. ForgeBoss records the refusal in Repair Rat memory.
2. A $0 local evidence collector extracts concrete engineering identifiers from the concise summary/reasoning summary.
3. It searches the exact retained repository locally and attaches the new findings to the next focused repair.
4. One retry is allowed only when genuinely new local evidence was found.
5. If nothing new can be gathered, ForgeBoss stops instead of paying for the same answer again.

The run report now includes WHY a cycle failed/stopped, the concise AI/repair summary,
engineering rationale, failure fingerprint, exact failed tests, failure lines/output tails,
files changed, code diff, token usage, model lane, and a recommended next action.

The dashboard adds Current Blocker, Repair Rat Memory and Next Best Action intelligence cards,
plus a richer Last Run Intelligence panel and OPEN FULL DIAGNOSIS action.
