# ForgeBoss v0.4 — Category League
Use **RUN $1 ALL-CATEGORY LEAGUE**. It benchmarks relevant executors across 8 controlled categories: database, backend/API, auth/security, frontend/UI, small bugfix, multi-file refactor, CI/build, and tests/regression. Winners become benchmark designations for future routing; they do not receive merge/deploy authority. Deep Agents remains a durability layer, not a coding contestant.

The $1 is a target experiment budget, not an absolute billing guarantee: mini-SWE has a hard framework cost limit; OpenHands can only be rejected after an SDK call; OpenCode does not yet expose a stable ForgeBoss dollar meter. Headroom is reserved.
