# ForgeBoss v0.2 Dashboard
Double-click `START-FORGEBOSS.cmd`. It opens a local dashboard on 127.0.0.1:8765.
Duration and session API budget are hard session controls. v0.2 enforces one writer.
Upstream executors are visible and can be checked at $0, but Repair Rat remains the live default until a same-task benchmark proves another executor better.
